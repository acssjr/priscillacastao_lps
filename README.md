# Landing Page — Priscilla Castão

Repositório de trabalho para pesquisa, direção visual, planejamento e, somente após aprovação, implementação da landing page de Priscilla Castão.

## Status atual

- pesquisa pública do Instagram consolidada;
- referências `iasmin-psi` e `gfb_lp` estudadas no código e no navegador;
- princípios de Revenue-Centric Design traduzidos para o projeto;
- quatro peças da identidade visual centralizadas;
- três fotos e uma capa de vídeo baixadas e convertidas para WebP;
- nenhuma linha de código da landing page criada.

A implementação só começa depois de validar oferta, público prioritário, prova, localização, agenda e CTA principal. O plano atual explicita hipóteses; ele não transforma inferências em promessas comerciais.
